# 📄 Carpeta de documentos

Acá podés poner tu CV en PDF para que los recruiters puedan descargarlo.

## Cómo agregar tu CV descargable

1. Guardá tu CV con el nombre `cv-ana-lujan.pdf` en esta carpeta

2. En `index.html`, buscá los botones del Hero y agregá este botón nuevo:
```html
<a href="docs/cv-ana-lujan.pdf" download class="btn-outline">
  Descargar CV ↓
</a>
```
